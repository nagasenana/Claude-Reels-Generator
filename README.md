The reels-generation department of Geoneo's AI agent company.

## Skills

Video-editing skills live in `.claude/skills/` and load automatically in Claude Code:

- **HyperFrames** (HeyGen) — HTML-based compositions; captions, motion graphics, explainers, product launch videos.
- **Remotion** — React-based compositions; start with `remotion-best-practices`.

See [`.claude/skills/SOURCES.md`](.claude/skills/SOURCES.md) for upstream versions and licenses.
